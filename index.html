Why tight bounds?

Looser bounds mean more wasted ray–box and ray–triangle tests.

What is a SOBB?

A skewed OBB: three arbitrary slab pairs — same memory as an OBB, same slab intersection test.

Fitting SOBBs — EG25 in one slide

Temporary k-DOP per node → pick 3 slab directions → SOBB.
2.6× faster to build than DiTO-based OBB fitting — comparable or faster tracing.

Takeaways

  1. 01Static: 1.07–1.6× faster secondary-ray traversal than state-of-the-art compressed 8-ary AABB BVH (BVH8) — Sheep: 9.3×.
  2. 02Dynamic: SOBB refit ≈ 1.5× an AABB refit — the trace advantage survives.
  3. 03Modest costs: +14–26% build, +5% memory, 7–15 bits/node.
